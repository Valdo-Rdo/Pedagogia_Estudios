📖 ¿Qué es la Neuroevolución?

La neuroevolución es una técnica de inteligencia artificial que utiliza algoritmos evolutivos para entrenar redes neuronales artificiales. A diferencia del backpropagation, no requiere gradientes y puede explorar espacios de soluciones más amplios.

🧬 Algoritmo Genético Implementado

1. Inicialización: Población aleatoria de redes neuronales.
2. Evaluación: Cada agente interactúa con el entorno y recibe un fitness.
3. Selección: Torneo — se eligen padres compitiendo aleatoriamente.
4. Cruce: Recombinación uniforme de pesos entre padres.
5. Mutación: Ruido gaussiano aplicado a los pesos.
6. Elitismo: Los mejores pasan intactos a la siguiente generación.

🎯 Función de Fitness

El fitness combina múltiples señales:

F = α·Δdist + β·reach + γ·survive − δ·collisions + ε·exploration

• Δdist: reducción de distancia al objetivo (gradiente)
• reach: bonus grande por alcanzar el objetivo
• survive: recompensa por mantenerse activo
• collisions: penalización por chocar con obstáculos
• exploration: bonus por movimiento (evita quedarse quieto)

🚗 Modelo de Movimiento

Se usa un modelo differential drive (tipo robot de dos ruedas):

v = (v_L + v_R) / 2
ω = (v_R − v_L) / L
x' = x + v·cos(θ)·dt
y' = y + v·sin(θ)·dt
θ' = θ + ω·dt
