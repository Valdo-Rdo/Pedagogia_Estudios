📉 Dinámica Poblacional
🔬 Marco Teórico

Modelo: Sistema multi-agente con genotipo tri-dimensional (H, S, L) mapeado a HSL. Cada célula posee fitness dependiente del ambiente.

Selección natural: Individuos con mejor adaptación al entorno actual tienen mayor probabilidad de replicarse (selección direccional/estabilizadora).

Fusión colonial: Células compatibles genéticamente pueden formar colonias con ventajas cooperativas (simbiosis).

Mutación: Deriva genética estocástica sobre los tres loci. Tasa configurable.

Capacidad de carga (K): Limitación logística tipo Verhulst. Aumenta la presión selectiva cuando N → K.

Interacción: Clic en el lienzo para sembrar una colonia. Shift+clic para análisis individual.
